A simple demonstration of good HTML5 structure and basic responsive CSS.

## Features
- Semantic elements: `header`, `nav`, `main`, `article`, `section`, and `footer`
- Proper document language, character encoding, and viewport metadata
- External stylesheet (`style.css`)
- Meaningful headings and a semantic list

## Run locally
Open `index.html` in a web browser.

## GitHub Pages
This repository is designed to publish from the `main` branch, root (`/`). The homepage is `index.html`.
